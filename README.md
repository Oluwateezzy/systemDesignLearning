# System Design Learning

A collection of practical projects and demonstrations for learning system design concepts.

## 📂 Projects

### 1. [Book Library Indexing](./book-library-indexing)
A deep dive into database indexing performance using NestJS and Prisma.
- **Concepts:** B-Tree Indexes, Hash Indexes, Query Optimization, Full-Text Search.
- **Demo:** Benchmarks showing 100x+ performance improvements with proper indexing.
- **Article:** [Indexing Deep Dive](./book-library-indexing/INDEXING_DEEP_DIVE.md)

### 2. [Distributed Job Scheduler](./distributed-job-scheduler)
Implementation of a distributed job scheduling system.
- **Concepts:** Distributed Systems, Job Queues, Scheduling Algorithms.

### 3. [URL Shortener & Observability](./url-shortener-observability)
A URL shortener service with a focus on observability.
- **Concepts:** System Design, Metrics, Logging, Tracing.

### 4. [Proxy & Reverse Proxy](./proxy-reverse-proxy)
Demonstration of proxy and reverse proxy patterns.
- **Concepts:** Load Balancing, Caching, Security.

## 🚀 Getting Started

Each project is self-contained. Navigate to the project directory and follow the README instructions.

```bash
# Example: Running the indexing demo
cd book-library-indexing
yarn install
yarn start:dev
```
